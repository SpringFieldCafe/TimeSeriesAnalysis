完成本地实验五题目的四组数据、十条序列分析：生产记录的平稳性与纯随机性、绵羊数量预测、三个人口指标和五个农场指标的差分建模与预测。沿用实验四的交付方式，保存代码、数值结果和 Matplotlib 图，暂不制作 Word/PDF 报告。

## 方法和选择规则

显著性水平为5%。ADF 的原假设是存在单位根；KPSS 的原假设是水平平稳。主检验均含常数项，ADF 预设最大滞后为4并以 AIC 选阶，KPSS 使用自动带宽。ADF 的软件默认最大滞后另作敏感性对照；原序列另保存含线性趋势的 `ct` 检验。KPSS 查表范围为0.01–0.10，边界以不等号表示。未拒绝原假设不等于证明其成立。

低滞后上限用于减少短年度样本中滞后参数过多带来的检验功效损失，并非根据结果临时选取。38个观测时，软件默认 ADF 对出生率和自然增长率的差分序列会选择9、10阶，分别给出 p≈0.953、0.969；主设定均选择0阶，分别为9.14e-6、4.21e-6。原序列的默认 ADF 反而拒绝单位根。结论对设定敏感，因此结合 KPSS、时序图和差分后的相关结构判断，不能将任何单次 ADF 结果写成确定事实。全部对照见 `diagnostics.csv` 和 JSON。

对每条序列计算0、1、2阶普通差分诊断，选取同时满足主 ADF p<0.05、KPSS p>0.05的最小阶数；二阶仅作对照，不因某项检验更显著而继续差分。结果为生产记录 d=0，其余 d=1。这是本实验的明确建模规则，不证明序列一定恰有相应数量的单位根。玉米价格和生猪价格的 `ct` 检验也与趋势平稳解释相容；本次按题目的差分路线建模，其他趋势模型可能得到不同外推。

原序列与所选差分序列均保存 ACF/PACF。最多展示20阶，短人口序列按样本量限制为原序列18阶、一阶差分17阶；ACF 使用分母 n 的样本自协方差、Bartlett 95%逐阶参考区间，PACF 使用 `ywm` 和约 ±1.96/√n 区间。截尾、拖尾只作识别线索，孤立越界不直接确定模型；各阶区间和检验均未作多重比较校正。

原始/差分序列的纯随机性列出 Ljung–Box 的1、6、10阶结果。对非平稳原序列，水平值的检验仅作描述；应在平稳变换后讨论线性相关性。白噪声不是独立同分布的同义词，未拒绝某个滞后范围内的无自相关假设不证明完全随机。

固定 d 后，每条序列比较30个 ARIMA 候选：p、q 均为0–4且 p+q≤4；d=0 比较有均值和零均值，d=1 比较有漂移和无漂移。含 `(0,1,0)` 的随机游走作为基线。使用状态空间极大似然估计，约束 AR 平稳、MA 可逆；先统一缩放改善数值优化，再把参数、拟合、预测和似然准则还原到给定数值尺度。没有引入季节模型，年度数据也没有月度季节周期信息。

选择时先要求收敛、AICc 有限、残差在6阶和10阶的 Ljung–Box p值均>0.05，再在合格候选最小 AICc 的2以内选参数总数最少者，同参数数目时选 AICc 更小者。参数数目含均值/漂移与创新方差。残差使用剔除弥散初始化后的标准化一步预测误差，自由度扣除 p+q。AICc 只在同一条序列、同一 d 下比较，不能跨指标比较大小；300个候选中297个收敛，3个未收敛候选均排除，全部候选、收敛状态和优化警告均保存。

预测区间是给定所选模型和估计参数的条件95%逐期预测区间，包含未来创新的不确定性，未计入参数估计和模型选择的不确定性，也不是全预测路径同时覆盖95%的区间。题目第一问所称下一时刻“置信区间”按下一次观测的预测区间实现。样本内拟合为一步预测，不能将其误差当成样本外预测精度；本题未提供未来真实值，不宣称已验证未来预测效果。历史数据终点决定预测起点，未混入后来年份的实际数据。

区间使用高斯创新近似。Jarque–Bera 在5%水平下拒绝出生率、死亡率、自然增长率、玉米产量、工资、生猪产量残差的正态性，其中工资与生猪产量有明显尾部异常；对应 p值保存在 JSON。因此这些区间应作为模型给出的名义95%区间，不能声称真实覆盖率已达到95%。无自相关检验通过也不能消除分布和方差随时间变化的风险。

## 1 连续生产记录

原序列 ADF 拒绝单位根、KPSS 未拒绝水平平稳；Ljung–Box(1) p=2.04e-5、(10) p=0.000260，拒绝相应滞后范围的无自相关假设，支持平稳且非白噪声的处理方式。ACF 第一阶为负且较突出，之后较小；PACF 前几阶逐渐衰减，支持把 MA(1) 纳入候选。

所选模型为：

```text
x_t = 84.129682 + ε_t - 0.477523 ε_(t-1)
Var(ε_t) = 7.162731
```

MA 多项式根模约2.0941，满足可逆性。下一次记录（t=202）的点预测为 **85.6803**，预测标准误为 **2.6763**，条件95%预测区间为 **[80.4348, 90.9258]**；完整数值见 `results/e4_8_forecast.csv`。图中用带端帽的误差线显示单时点区间。

## 2 英国绵羊数量

原序列均值随时间变化、ACF 缓慢衰减，原序列检验支持按非平稳处理。一阶差分后，主 ADF、KPSS 共同支持近似平稳；差分序列 LB(10) p=0.000297，仍有可建模相关性。差分 ACF 由正转负并振荡衰减，PACF 前三阶较突出，因此比较含 AR(3) 的候选。

```text
Δx_t = 0.464251 Δx_(t-1) - 0.237760 Δx_(t-2) - 0.279587 Δx_(t-3) + ε_t
Var(ε_t) = 4779.360755
```

所选 ARIMA(3,1,0) 无漂移。第二阶 AR 系数单独检验 p≈0.096，不能声称所有参数均显著；本次按整模型诊断和信息准则保留该候选，未逐项删减参数。1939–1945年逐年预测及区间见 `results/sheep_forecast.csv`，数量单位沿用原数据。

## 3 我国三个人口指标

出生率与自然增长率原序列有明显水平变化，死亡率也不宜据相互不确定的检验结果直接认定平稳。三条序列一阶差分后主检验支持近似平稳。出生率与自然增长率差分 ACF 第一阶为正，PACF 有衰减表现，模型比较选中 MA(1) 差分误差；死亡率差分 LB(10) p≈0.734，随机游走已满足当前诊断，不强加额外动态项。

```text
出生率：Δb_t = ε_t + 0.717896 ε_(t-1)，Var(ε_t) = 0.564235
死亡率：Δm_t = ε_t，Var(ε_t) = 0.010527
自然增长率：Δg_t = ε_t + 0.784803 ε_(t-1)，Var(ε_t) = 0.593735
```

2018–2027年三组预测分别见 `birth_rate_forecast.csv`、`mortality_forecast.csv`、`ngr_forecast.csv`。无漂移 MA(1) 差分模型在第一期以后给出水平的点预测，不能据此推断未来人口率恒定。只有38个年度观测，十年外推和 ADF 设定敏感性均限制结论的可靠程度。

三个独立模型的出生率减死亡率为4.3143，自然增长率独立预测为4.0830，相差约0.2312。`population_identity_comparison.csv` 同时列出独立预测和由前两者相减得到的点预测，后者仅供恒等关系对照；未在缺少联合协方差估计时拼造其预测区间，也未用对照值覆盖题目要求的独立模型结果。

## 4 农场五个指标

五条原序列存在水平或趋势变化，按所定规则采用一阶差分，不再二阶差分。玉米价格差分 LB(10) p≈0.141，随机游走足以作为简约候选；玉米产量差分第一阶 ACF 约-0.497，选择负 MA(1)；工资差分 ACF 逐渐衰减，选择 AR(1)；生猪价格差分表现出振荡相关，选择 AR(3)；生猪产量差分仍有中低阶相关，比较后选 ARMA(1,3) 差分误差。

令各指标 z_t=Δx_t，所选模型为：

```text
玉米价格：z_t = ε_t，Var(ε_t) = 0.028652
玉米产量：z_t = ε_t - 0.571464 ε_(t-1)，Var(ε_t) = 0.003627
工资：z_t = 0.534818 z_(t-1) + ε_t，Var(ε_t) = 0.001051
生猪价格：z_t = 0.233084 z_(t-1) - 0.238393 z_(t-2)
                  - 0.315576 z_(t-3) + ε_t，Var(ε_t) = 0.011164
生猪产量：z_t = -0.962557 z_(t-1) + ε_t + 1.030342 ε_(t-1)
                  - 0.297958 ε_(t-2) - 0.462371 ε_(t-3)，Var(ε_t) = 0.002391
```

五条序列1948–1957年的逐年点预测、标准误和上下限见各自 `results/*_forecast.csv`。生猪价格 AR(2) 项和生猪产量 MA(2) 项的单独检验接近但未达到5%水平；生猪产量的 AR 系数接近-1，虽满足平稳根约束，长期振荡和参数不确定性仍需谨慎。没有将“通过两项残差检验”解释为证明模型正确；Q-Q图、误差分布和残差 ACF 均单独保存，用于检查正态近似和剩余结构。

## 文件与核对

- `analysis.py`：读取4个 CSV，生成全部分析图和数值结果；`requirements.txt`：本实验依赖。
- `figure/`：49张200 dpi PNG。每条序列保存时序/差分、原序列 ACF/PACF、拟合与预测、四面板残差诊断，另为9条差分序列保存差分 ACF/PACF。代码使用 Matplotlib 的 `Agg` 后端和 `savefig`，运行后图文件会实际落盘。
- `results/diagnostics.csv`：30行0–2阶差分检验及默认 ADF 对照；`results.json`：版本、设置、趋势检验对照、完整参数和预测。
- `results/model_summary.csv`：10条序列的模型、诊断和预测摘要；`*_model_comparison.csv`：每条序列30个候选及警告。
- `*_parameters.csv`、`*_fitted.csv`、`*_innovations.csv`、`*_residual_ljung_box.csv`：参数、有效样本内拟合、标准化创新和残差整体检验。
- `*_forecast.csv`：题目指定全部未来时点的点预测、预测标准误、95%预测上下限；`*_correlations.csv`：ACF/PACF与逐阶区间。
- `population_source_identity.csv`、`population_identity_comparison.csv`：原始人口指标恒等式偏差及独立预测对照。
- `verify_results.py`：读取实际生成文件，独立按 ARMA 方程逐期递推全部预测，核对 AICc 校正、模型选择规则、时间范围、区间、特征根、残差检验和49张图的落盘情况。该核对验证计算一致性，不代替样本外预测验证。
