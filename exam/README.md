# 时间序列分析课程考查

本目录按课程试题完成两项任务：188个月的屠宰量分析与未来96个月预测；截至2018年2月的14,592小时油温分析与未来168小时预测。依照本次明确约定，代码、数据副本、结果、图表和本地报告均集中于 `exam/`。原始试题、Excel与CSV不修改，先做本地备份，再在Word副本中填充。

## 环境与运行

使用已有Anaconda `base`，不新建环境。实测Python 3.13.9、NumPy 2.3.5、pandas 2.3.3、statsmodels 0.14.5、scikit-learn 1.7.2；完整版本与配置见 `results/configuration.json`。限制2线程，第一轮分析约571秒，实际时长受机器负载影响。

在仓库根目录运行：

```powershell
conda activate base
python exam/analysis.py
python exam/supplementary_analysis.py
python exam/make_figures.py
python exam/verify_results.py
```

Word处理另需Windows上的Microsoft Word和pywin32。当前机器已具备；报告生成工具通过原生Word操作副本，保留前面的试题、封面、表格、图形和页面设置。页面图像的内部检查使用运行时附带的Poppler。

```powershell
python exam/report_tools.py prepare
python exam/write_report_content.py
python exam/report_tools.py build
```

上述 `analysis.py` 在课程原件存在时重新提取数据并首次备份；Git不保存含作者等元数据的Excel原件。仅有Git文件时，分析自动使用 `data/` 中的纯数据快照，也可完整运行分析与数值复核。生成Word还需把课程试题原件放回本目录，并先运行模板准备命令。缺少本地原件时，验证脚本将原件保护两项标记为不可检查，不能据此宣称原件已经核验。补充依赖时使用南京大学镜像：

```powershell
python -m pip install -r exam/requirements.txt -i https://mirror.nju.edu.cn/pypi/web/simple
```

## 目录

- `analysis.py`：原始数据核对、分解、候选模型、历史回测、冻结选择和最终预测。
- `supplementary_analysis.py`：主结果冻结后的月度季节结构敏感性分析，不回改主预测。
- `make_figures.py`：15张报告图与最终残差诊断。
- `write_report_content.py`：以实际数值结果组织逐题正文，生成最终参数表。

- `verify_results.py`：独立复算误差和区间指标、检查时间边界与原件校验值、生成成果哈希清单。
- `data/`：纯数据CSV，油温训练与最终核验目标分开保存。
- `results/`：逐次拟合参数日志、候选比较、逐期预测、区间、诊断与验证记录。
- `figures/`：报告引用的15张PNG图。
- `backup/`、`report/`、`qa/`：本地原件备份、最终Word副本和内部检查资料，全部忽略，不上传。

## 数据与严格边界

| 任务 | 训练数据 | 预测目标 | 检验 |
| --- | --- | --- | --- |
| 屠宰量 | 1980-01至1995-08，188个月 | 1995-09至2003-08，96个月 | 4个24个月验证起点；最后24个月留出；2个96个月压力检验 |
| 油温 | 2016-07-01 00时至2018-02-28 23时，14,592小时 | 2018-03-01 00时至03-07 23时，168小时 | 11个月末验证起点；8个冬季留出周；冻结后核验最终一周 |

文件2的2018年3月8日之后观测不使用。对每个历史起点，拟合、滚动统计和标签都截止于当时；完整168小时预测过程中不接收新的真实OT，也不读取未来真实负荷。MSTL全训练期分解仅用于描述，不输入较早回测起点。树模型提前停止关闭，避免库默认随机验证拆分。

屠宰量保留给定月度总量，不补写未经提供的城市或事件原因。日历校正为月总量除以日历天数，不等于按实际开工日校正。油温保留给定尺度，含非正值，不取对数、不使用温度百分比误差。

## 技术配置与选择

月度主比较为13个候选：季节朴素基准、原总量/日历校正下的3种ETS、2种尺度下的3种SARIMA。对数预测还原时以 `exp(mu+variance/2)` 得均值，以对数正态分位数得正值区间。

油温比较15个候选：3个朴素基准；90天/180天/全部历史窗口下的日周期与日周周期统计模型；同样3个窗口下仅OT与增加历史负荷的树模型。统计模型的AR滞后为1、2、3、24、25、48、168小时，日周各2对谐波项。树模型在日末起点直接学习 `OT(t+h)-OT(t)`，共享不同步长h的模型，使用25或55维已知特征；100次迭代、15叶节点、学习率0.06、最小叶样本35、L2正则10、随机种子20261029。统计窗口限定拟合目标时段，构造滞后允许向此前已知历史获取；树模型为30天历史特征与完整7天标签预留边界，实际监督样本数逐次记录。

先比较验证RMSE，在最佳值的1%以内，依次按区间得分、起点间误差稳定性、MAE选择。此规则运行前固定。区间得分同时惩罚宽度和漏覆盖，不以覆盖率单项择优。最终检验不回改冻结配置。

## 主要结果与解释

- 月度冻结主模型：原总量对数SARIMA(1,0,1)×(0,1,1)12。验证RMSE约11,354.60；最后24个月留出RMSE约8,980.04，去年同月基准约11,772.17。日历校正略改善同结构RMSE，但幅度不足1%，主模型的区间综合得分更低。残差仍有季节相关，未宣称已完全白噪声。
- 油温冻结主模型：180天窗口的日周周期稀疏自回归。验证RMSE约3.209、区间覆盖95.51%；冬季留出RMSE约2.914、覆盖91.59%；最终一周RMSE约3.068、覆盖94.64%，存在整体偏高。
- 树模型仅OT在冬季留出与最终一周的点预测更好，但95%分位区间覆盖不足，区间得分较差。不同模型对点预测和区间质量存在取舍，不能概括为某类算法普遍更好。
- 历史负荷增益依赖窗口：较短窗口中有改善，全部历史树模型中未改善。负荷之间高度相关，因此以整组增益讨论，不作单变量因果排名。
- 月度主拟合残差检查后增加2种季节AR结构作为补充敏感性研究，其验证RMSE较低，但诊断仍有剩余相关。该研究在主结果冻结后触发，单列协议和结果，不回改原主预测，不称为全新独立验证。

全部区间为给定所选模型及参数的名义逐期95%区间，不是整条路径的联合95%区间，也不完整涵盖结构变化、参数估计和模型选择的不确定性。月度历史不足以安排至少8年训练加8年完整独立测试；油温的8个留出周及一周最终核验也不是大量独立试验。

## 参数与验证记录

`results/fit_log.json` 保存每次拟合的模型配置、训练范围、最大标签时刻、参数、收敛状态、警告和耗时；`final_model_parameters.csv` 保存主模型系数，`configuration.json` 保存固定配置和版本。`monthly_selection.json`、`oil_selection_frozen.json` 是主模型选择记录；`sensitivity_protocol.json` 说明补充研究的触发和边界。逐期预测均含日期、步长、均值、95%上下限，回测另外含真实值及预测起点。

`verification.json` 为独立复算结果；`artifact_manifest.csv` 为本目录可提交成果的SHA-256清单。内部 `qa/template_verification.json` 核对原题前缀、段落格式、页面几何、原表格文字、图形对象、页眉页脚字段结构和原件哈希；逐页图像另作目视检查。
