# 时间序列分析实验

每份作业单独存放、提交并推送到对应分支。实验一位于 [`exp1/`](exp1/) 目录，并使用 `exp1` 分支；其中包含脚本、数据、依赖、说明和生成图表。

## 作业约定

- 每份作业使用独立目录和分支，按 `expN` 命名，例如 `exp2/` 与 `exp2` 分支。
- 作业代码、专属说明、依赖和输出都放在对应目录中；目录索引以各作业的 `README.md` 为准。
- Word/PDF 实验报告以及个人信息、凭据和本地环境文件由 `.gitignore` 排除。
- 对待提交文档逐份检查是否包含敏感个人信息；含有此类信息的文档一律不要上传。每次提交前都提醒模型检查待提交文件及文档内容，确认不含敏感个人信息后再推送。
- 环境优先使用本机 Anaconda；确需配置环境时使用南京大学镜像源。
